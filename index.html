A PRECISE RESULT IS A USEFUL RESULT

Know what the fence covers.

It observes declared local HTTP endpoints.

OutageFence checks supported synthetic marker representations, required controls, injected faults, call counts, and command outcomes. Raw request values and child output stay out of its reports.

Your application's wider environment is outside that boundary.

Hardcoded external URLs, databases, files, encrypted or transformed values, and provider retention are not observed. The child command is not sandboxed. Use synthetic data and separate network isolation when needed.

Early access v0.1.0-rc.2. Automated tests pass on Linux and macOS with Node.js 22. Windows execution, production use, independent adoption, and real-provider behavior have not been verified. No privacy guarantee or compliance certification.
